# Website image provenance

- `app-icon.png` is copied from the project's existing `Resources/AppIcon.png`.
- `menu.png` and `traffic.png` are native captures rendered from the project's SwiftUI views at app version 1.5.4.
- The captures use a temporary copy of the view sources, an in-memory traffic store, a synthetic network named `Mwifi 演示网络`, and illustrative September 2026 traffic values. Live polling is disabled in the capture harness. No actual SSID, router response, traffic database, or desktop pixels are included.
- The marketing page labels the captures as actual app interfaces with demonstration data. They illustrate functionality, not measured performance.
